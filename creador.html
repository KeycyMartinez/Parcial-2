Sobre mí

Keycy Martínez

Soy estudiante de Licenciatura en Desarrollo y Gestión de Software en la Universidad Tecnológica de Panamá. Este sitio es mi trabajo para la asignatura Desarrollo de Software V, y está dedicado a Docker y los contenedores.

Escogí el tema de Docker y contenedores porque es un tema con el que estuve trabajando recientemente en un proyecto de una aplicación web, por lo que fue el tema que más me llamó inmediatamente al ver la lista de propuestas.

Del desarrollo de este parcial aprendí a utilizar mejor HTML y CSS ya que quise que mi sitio web tuviera varios elementos visuales y que fuera un diseño muy creativo, así que, además de las tablas y contenedores, incluí una línea de tiempo, diagramas, comandos y colores en degradado para todo el sitio; al final quedé muy satisfecha con el resultado.
